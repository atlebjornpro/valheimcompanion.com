## Self-hosting requirements

Keen Games recommends a 6-core/12-thread CPU, 16 GB RAM, 30 GB of free SSD storage, and roughly 2 Mbit/s of upload capacity per active player for a 4-6 player server. A 16-player server calls for an 8-core/16-thread CPU at a higher clock speed.

The dedicated-server process uses about 4.4 GB of physical RAM while idle and can add up to 100 MB per player. Real performance still depends heavily on CPU speed, world activity, and the host's network.

## Current platform note

Keen's installation documentation currently lists **Windows as the supported dedicated-server platform** and says Linux support is planned. Re-check the official installation page before treating that as permanent.
