**Valheim 1.0 is scheduled for September 9, 2026.** Iron Gate has not published the final 1.0 patch notes yet. This page is the launch-status hub: it records what is confirmed, what still requires release-build verification, and where server owners and players should look when the update arrives.

Rumors, trailer interpretations, and unverified social posts are not treated as patch notes.

The latest official news post, published August 20, says the team is completing final bug fixes and preparing for release. It directs players back to the official 1.0 FAQ rather than publishing final mechanics or patch notes.

## What is confirmed for 1.0

- The release is planned for September 9, 2026.
- The Deep North is the main biome update.
- PlayStation 5 and Nintendo Switch 2 join the existing PC, Mac, Linux, and Xbox platforms.
- Crossplay is planned between all announced platforms.
- Existing characters and worlds remain usable.
- New world content generates correctly in unexplored areas; Iron Gate recommends a new playthrough for the intended full experience.
- Achievements begin tracking after 1.0 is installed, subject to the announced cheat and world-modifier rules.
- Iron Gate does not guarantee that existing mods will function at launch.
- Valheim remains a game for one to ten players.

Use the [complete Valheim 1.0 release guide](/valheim-1-0) for platforms, save compatibility, downloads, achievements, and the official announcement timeline.

## What still requires launch-day verification

The following details should not be copied from previews or unofficial databases before the public build is available:

- the final version and network protocol numbers;
- the complete patch notes and item list;
- Deep North progression gates, recipes, boss requirements, and balance;
- final storefront download and installed sizes;
- whether individual mods and mod loaders work;
- dedicated-server application or launch-argument changes;
- console-specific connection, performance, or control differences;
- newly reported bugs and confirmed workarounds.

## Launch-day update checklist

When 1.0 becomes public, Valheim Companion will review the release in this order:

1. Archive the official patch notes and release announcement URLs.
2. Record the public client, server, and network versions where officially exposed.
3. Compare the final platform and download information with the July FAQ.
4. Recheck old-world generation guidance and save-management warnings.
5. Verify Steam and PlayFab crossplay instructions against the released server manual.
6. Test clean, unmodded startup before reporting mod-related failures.
7. Review the Deep North, 1.0, preparation, achievements, requirements, and server-update pages.
8. Add only reproducible issues or issues acknowledged through Iron Gate's official support channels.

## Player preparation

Before installing the update:

- make an offline copy of important characters and worlds;
- preserve a separate pre-1.0 rollback copy;
- record active mods and world modifiers;
- decide whether to continue an existing world or begin a new one;
- leave the Deep North unexplored if clean generation in an established world matters;
- allow enough time and disk space for both the download and a safe backup.

Follow the [Valheim 1.0 preparation checklist](/valheim-1-0/preparation-checklist) for the complete workflow.

## Dedicated-server preparation

Server owners should schedule a maintenance window rather than allowing an unattended update:

1. Ask players to disconnect and stop the server cleanly.
2. Back up the authoritative world, permission files, launch configuration, and mod configuration.
3. Record the working server version and networking backend.
4. Update a copy or staged instance first where practical.
5. Confirm that the expected world loads, saves, restarts, and accepts a test client.
6. Keep the old application and world backup until the community accepts the updated server.

See [updating a Valheim server](/servers/updating-a-server) and [world backup and restore](/servers/world-backup-restore).

## Known issues policy

There is no meaningful list of **Valheim 1.0 launch issues** before the public launch build exists. Once released, an issue will be listed here only when at least one of these conditions is met:

- Iron Gate acknowledges it through official news, support, or known-issues channels;
- it is reproducible on a clean, unmodded copy of the current build;
- it is clearly isolated to a documented platform, server version, or mod dependency.

Each entry will include the affected version, platform or server context, confirmation source, safe workaround if one exists, and the date it was last checked. Speculation and destructive save-editing advice will not be presented as fixes.

If a server disappears after updating, begin with the [server-not-showing checklist](/servers/server-not-showing). If the world itself appears wrong, stop the server before further writes and use the [backup and restore guide](/servers/world-backup-restore).

## Reporting a problem

Iron Gate asks players to check its known-issues area before submitting a bug report. A useful report should include the current game version, platform, whether the problem reproduces without mods, the steps that trigger it, and relevant logs without passwords or join codes.

Valheim Companion is independent and cannot accept official game bug reports.
