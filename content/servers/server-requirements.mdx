Valheim's official FAQ states that servers are capped at ten players. The official dedicated-server guide documents current Linux library requirements and a Docker alternative for older distributions.

This initial page does not publish unofficial CPU, memory, storage, or bandwidth formulas. Hardware guidance will be added only after repeatable measurements or current first-party recommendations can be cited.

Sources: [official Valheim FAQ](https://valheim.com/faq/) and [dedicated-server guide](https://valheim.com/support/a-guide-to-dedicated-servers/).
