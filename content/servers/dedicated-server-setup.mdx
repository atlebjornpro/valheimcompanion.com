Iron Gate documents installing **Valheim Dedicated Server** from Steam's Tools library and configuring the supplied Windows or Linux launch script. The official default Steam networking port range is 2456–2457. The guide recommends editing a copy of the supplied script because application updates can reset the original.

This scaffold will expand into separately verified Windows and Linux procedures. Until then, use the [official dedicated-server guide](https://valheim.com/support/a-guide-to-dedicated-servers/) as the operational source of truth.
