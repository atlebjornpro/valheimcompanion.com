## Self-host vs managed hosting

**Self-hosting** means running `valheim_server.exe` or `valheim_server.x86_64` on your own hardware or a VPS you already control. It's free apart from electricity, but you're the one handling updates, port forwarding, and uptime. The full walkthrough is in [dedicated server setup](/servers/dedicated-server-setup), and the [configuration generator](/servers/server-settings) will build the exact launch line either way.

**Managed hosting** means paying a provider to run the server on their hardware — a web control panel, one-click updates, DDoS protection, automated backups, and a location near your players, without touching a router. A small Valheim plan typically runs a few dollars a month. The rest of this page covers that side.

## Crossplay matters for which backend you pick

Valheim's dedicated server runs on either the **Steam backend** (Steam users only, requires port forwarding for outside players) or the **PlayFab crossplay backend** (`-crossplay`, works across all launch platforms, traffic goes through a relay so port forwarding isn't required). Not every managed host defaults to the same backend or makes it equally easy to switch — confirm PlayFab/crossplay support with the host directly if your group spans platforms, and see the [crossplay guide](/servers/crossplay) for what each backend actually changes.
