If you've decided not to [self-host](/servers/dedicated-server-setup), the next question is *which managed host*. They all run the same Valheim dedicated-server binary under the hood, so the real differences are **price per slot, crossplay support, datacenter regions, and support quality**. This page compares the main options honestly, including where each one loses — see the [data sources](/data-sources) and [editorial policy](/editorial-policy) this site follows.

## Self-host vs managed hosting

**Self-hosting** means running `valheim_server.exe` or `valheim_server.x86_64` on your own hardware or a VPS you already control. It's free apart from electricity, but you're the one handling updates, port forwarding, and uptime. The full walkthrough is in [dedicated server setup](/servers/dedicated-server-setup), and the [configuration generator](/servers/server-settings) will build the exact launch line either way.

**Managed hosting** means paying a provider to run the server on their hardware — a web control panel, one-click updates, DDoS protection, automated backups, and a location near your players, without touching a router. A small Valheim plan typically runs a few dollars a month. The rest of this page covers that side.

## Crossplay matters for which backend you pick

Valheim's dedicated server runs on either the **Steam backend** (Steam users only, requires port forwarding for outside players) or the **PlayFab crossplay backend** (`-crossplay`, works across all launch platforms, traffic goes through a relay so port forwarding isn't required). Not every managed host defaults to the same backend or makes it equally easy to switch — confirm PlayFab/crossplay support with the host directly if your group spans platforms, and see the [crossplay guide](/servers/crossplay) for what each backend actually changes.

## Which should you pick?

For a **flat, no-fuss 10-player server**, <a href="https://shockbyte.com/billing/aff.php?aff=11289" rel="sponsored noopener" target="_blank">Shockbyte</a> is the simplest option. If **crossplay matters and you want a confirmed-working setup across three real size tiers**, <a href="https://supercraft.host/valheim-server-hosting/?fpr=atle10" rel="sponsored noopener" target="_blank">Supercraft</a> or <a href="https://g-portal.com/?ref=palcompanion" rel="sponsored noopener" target="_blank">GPORTAL</a> both explicitly support it. For a **temporary or launch-week server**, GPORTAL's 3-day entry plan avoids paying for a full month. If your group is **heavily modded**, avoid Nitrado's ValheimPlus-only limitation and look at Shockbyte, Supercraft (M/L), or Sparked Host instead. If it's your **first time running any game server**, <a href="https://billing.apexminecrafthosting.com/aff.php?aff=16993" rel="sponsored noopener" target="_blank">Apex</a>'s panel and support reputation are worth the premium. And for **enterprise hardware with the widest datacenter footprint on this page**, <a href="https://billing.sparkedhost.com/aff.php?aff=3350" rel="sponsored noopener" target="_blank">Sparked Host</a> is the pick.

There's no single "best" — it depends on your group size, whether you need crossplay, and how much setup effort you want to avoid.
