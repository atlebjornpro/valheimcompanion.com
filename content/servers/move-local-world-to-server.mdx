---
title: Move a Local Valheim World to a Server
description: Migration-guide scaffold for transferring a local Valheim world to a dedicated server.
updated: 2026-08-04
---

The dedicated-server application can launch a named world from its configured save location. Exact source folders can vary with platform and save configuration, while `-savedir` can override the server's default location.

This page will document local, cloud-managed, Windows, Linux, and managed-host transfers after each path is verified. The initial scaffold deliberately avoids file-moving commands that could overwrite a player's only copy.

Source: [Iron Gate dedicated-server guide](https://valheim.com/support/a-guide-to-dedicated-servers/).
