Iron Gate's guide identifies **Game server connected** as the ready-state message. It also documents that `-public 0` hides a server from the browser and that PlayFab crossplay servers cannot be tested through a local or loopback address.

This page will become a step-by-step diagnostic for startup, visibility, backend selection, version matching, and connectivity. It currently avoids unsupported router- or platform-specific fixes.

Source: [official dedicated-server guide](https://valheim.com/support/a-guide-to-dedicated-servers/).
