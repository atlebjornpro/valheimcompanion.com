Valheim 1.0 is expected to download at approximately **4.3 GiB on most platforms** when it releases September 9, 2026. Iron Gate estimates about **3.0 GiB on Xbox One** and about **6.5 GiB for the Mac App Store and Microsoft Store versions**.

The PC, Mac, and Linux requirements below are the current official Steam storefront specifications reviewed on September 4. Iron Gate has not separately labelled them as final 1.0 requirements, so check the storefront again after launch if your system is close to the minimum.

## Official download-size estimates

| Platform or store | Estimated 1.0 download |
|---|---:|
| Most platforms | About 4.3 GiB |
| Xbox One | About 3.0 GiB |
| Microsoft Store | About 6.5 GiB |
| Mac App Store | About 6.5 GiB |

These are download estimates, not a guarantee of the final installed footprint. Updates can also require temporary free space to unpack and replace files. Leave additional headroom rather than clearing exactly the listed amount.

Valheim is Steam Deck Verified according to Iron Gate's general FAQ. Verification is a compatibility designation, not a guarantee that every graphics setting, large base, or heavily modded world will maintain the same performance.

## Will large builds run faster in 1.0?

Iron Gate says 1.0 includes performance improvements such as reduced microstutter when loading zones, faster saving, and other smaller optimizations. It specifically cautions that large builds are not expected to benefit as much as players might hope.

If a settlement already struggles, preserve the world and test the final build before promising a particular frame-rate improvement. Mods, server latency, world size, smoke and light sources, and the density of structures can all complicate comparisons.

## Client requirements are not server requirements

The Steam client specifications include rendering hardware that a headless dedicated server does not need. Server sizing depends more heavily on CPU performance, memory headroom, world activity, player distribution, and any mods.

Iron Gate officially supports 1–10 players. It does not publish a simple RAM-per-player formula for dedicated servers. Use the [server requirements guide](/servers/server-requirements) instead of applying the client graphics table to hosting hardware.

## Frequently asked questions

### How big is the Valheim 1.0 download?

Iron Gate estimates about 4.3 GiB on most platforms, 3.0 GiB on Xbox One, and 6.5 GiB for the Mac App Store and Microsoft Store versions.

### How much RAM does Valheim need on PC?

The current Steam requirements list 8 GB RAM minimum and 16 GB recommended for Windows, macOS, and Linux clients.

### Is Valheim Steam Deck verified?

Yes. Iron Gate's FAQ states that Valheim is verified for Steam Deck and supports controllers.

### Will Valheim 1.0 improve performance?

Iron Gate confirms reduced zone-loading microstutter, faster saves, and other optimizations, but says large builds in particular will not be highly affected.

### Are these dedicated-server requirements?

No. The tables are client requirements from the Steam storefront. Dedicated servers have different workloads and do not need a gaming GPU.
