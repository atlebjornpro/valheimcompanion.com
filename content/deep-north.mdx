The Deep North arrives with **Valheim 1.0 on September 9, 2026**. It is the final biome update that brings the game out of Early Access and the main focus of version 1.0.

Iron Gate says players can head directly north after updating, but recommends starting over for the intended full experience. Existing worlds remain usable; new biome generation works properly only in unexplored areas.

## What is the Deep North?

The Deep North is Valheim's frozen northern biome. Iron Gate has shown landscapes, gathering, building, crafting, snow, and ice features in developer posts, while keeping major progression and combat details undisclosed.

The release announcement confirms new enemies, weapons, and building opportunities. It does not yet provide complete recipes, statistics, resistance requirements, boss information, or progression gates.

## Officially confirmed previews

| Preview | What Iron Gate has shown |
|---|---|
| Frost Foundry | A new workshop addition associated with extreme cold |
| Lingonberries | Harvestable in the biome's woods and used in food recipes |
| Slippery ice | A surface where careless movement can cause stumbling |
| Deep snow | Snow that must be cleared to build in some places |
| Shovel | A craftable tool for clearing deep snow |
| 67-degree roofs | Four-meter-high pieces for thatch and darkwood styles |
| Drawbridge | A new build piece previewed in April 2026 |
| Loom | A crafting extension for the Galdr table |

These are previews, not a complete feature list. Their final recipes, balance, and progression placement remain subject to the launch build.

## What remains unconfirmed

This guide intentionally does not claim:

- boss identities or encounter requirements;
- enemy health, damage, weaknesses, or spawn locations;
- armor, food, or resistance thresholds;
- resource maps or optimal farming routes;
- exact crafting recipes;
- the biome's complete progression order;
- server or client hardware changes caused by the biome.

Those details will be added only after launch patch notes or hands-on verification.

## Can existing worlds generate the Deep North?

Yes, with an important limit. Iron Gate says an old world receives new content, but biome generation works properly only in areas that have not been explored.

The studio has not published a technical radius that lets this site guarantee whether a specific location is untouched. If the north was visited and clean generation is essential, start a new world. If preserving the existing world matters more, back it up and test a copy.

Use the full [existing world versus new world decision guide](/servers/existing-world-vs-new-world) before choosing.

## Should players avoid exploring north before release?

Avoiding the Deep North is the conservative option for players who want to keep an existing world. This is an inference from Iron Gate's confirmed unexplored-area rule, not a promise that every unvisited-looking map cell will generate identically to a new world.

Do not use unofficial terrain-upgrade tools on the only copy of an important world. Their behavior is outside Iron Gate's support guidance.

## Character preparation checklist

- [ ] Back up character saves before installing 1.0.
- [ ] Decide whether the character's existing inventory should enter the new biome.
- [ ] Review achievement restrictions if developer commands or marked items were used.
- [ ] Record active mods and wait for compatibility updates.
- [ ] Avoid treating teaser images as equipment or resistance requirements.

Old characters remain usable. Starting a new world does not require deleting them, although a group may choose fresh characters for a complete restart.

## World preparation checklist

- [ ] Decide whether the Deep North has already been explored.
- [ ] Make an offline copy of the world files.
- [ ] Keep the pre-1.0 copy unchanged.
- [ ] Document world modifiers and mod dependencies.
- [ ] Test the updated copy before overwriting any rollback point.
- [ ] Check important builds and portals after loading.

For file-handling steps, use the [world backup and restore guide](/servers/world-backup-restore).

## Dedicated-server preparation

Server owners should treat the 1.0 update as a planned maintenance event.

1. Announce the maintenance window and stop new logins.
2. Shut down the process cleanly.
3. Copy the authoritative world, character policy, permission files, and launch configuration.
4. Record the current application and mod versions.
5. Update the server separately from the client test plan.
6. Confirm version compatibility, world loading, server visibility, and crossplay.
7. Keep the rollback files until the community accepts the result.

Follow the [server update guide](/servers/updating-a-server) and [dedicated-server setup reference](/servers/dedicated-server-setup).

## Mod preparation

Iron Gate provides no official mod support and does not guarantee 1.0 compatibility. There is no planned Steam Workshop or console mod support at launch.

For a modded server, archive the mod list and configuration alongside the world backup. Wait for mod authors to publish compatible versions, and reproduce a problem on a clean test copy before assuming the Deep North update itself is responsible.

## New world or existing world?

| Situation | Lower-risk approach |
|---|---|
| Never visited the Deep North | Back up and test the existing world |
| Explored northern terrain | Start a new world for clean generation |
| Large community base is the priority | Preserve the old world and evaluate a copy |
| Complete intended progression is the priority | Start from scratch, matching Iron Gate's recommendation |
| Heavily modded save | Wait for compatibility confirmation and test offline |
