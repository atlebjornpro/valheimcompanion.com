When you run an Enshrouded dedicated server at home, reliability matters more than gaming-router branding. The router needs dependable port forwarding, a reserved internal address for the server, enough capacity for the rest of the household, and stable uptime.

Enshrouded uses query port **15637** by default and currently supports up to **16 player slots**. Keen Games recommends about **2 Mbit/s of upload capacity per player**. The server machine should be connected by ethernet whenever possible.

## What matters for self-hosting

- **Port forwarding:** the interface should make it easy to send the configured query port to the server PC.
- **DHCP reservation:** keeps the server on the same local IP after reboots.
- **Reliable uptime:** a shared world may remain online continuously.
- **Gigabit ethernet:** sufficient for the server and most home internet connections.
- **Useful QoS:** can prevent large household downloads from disrupting a session.
- **A wired server connection:** reduces packet loss and latency variation.

Wi-Fi 7, RGB lighting, and gaming acceleration labels are not required to host Enshrouded.

## Choose by situation

- **Occasional world for a few friends:** keep a recent router, reserve the server IP, and use ethernet.
- **Persistent world in a busy household:** consider the mid-tier router and a small UPS.
- **Up to 16 active players:** verify upload capacity, server CPU, and memory before blaming the router.
- **No interest in network administration:** use a provider from the [managed hosting comparison](/guides/server-hosting).

Always confirm the current Enshrouded server configuration in Keen Games' documentation before opening ports. Expose only the port you need, keep the host operating system updated, and protect administrative access.
