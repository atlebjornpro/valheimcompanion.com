The most reliable way to contact the project is through its public issue tracker:

[Open an Enshrouded Companion issue](https://github.com/atlebj/EnshroudedCompanion/issues/new)

## What to include

For a correction or outdated guide:

- The page URL.
- The statement or value that appears incorrect.
- Your game and server version.
- A screenshot, official source, or steps that reproduce the result.

For a tool problem:

- The tool and inputs used.
- The result you expected.
- Browser and device.
- Any error shown on screen.

For server problems, never post passwords, private IP addresses, API keys, access tokens, billing details, or an unredacted configuration containing credentials.

## Appropriate topics

Issues may be used for:

- Content corrections.
- Updated resource locations or routes.
- Tool bugs and feature suggestions.
- Accessibility problems.
- Broken links.
- Editorial, privacy, or affiliate-disclosure questions.

The issue tracker is public. Do not include personal information you do not want visible to others.
