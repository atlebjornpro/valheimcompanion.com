**Released September 11, 2026.** The announcement labels **1.0.12 Steam only**, with crossplay retained and other-platform fixes planned. This entry preserves that announcement's scope.

## What changed

- Forge of Potential no longer unlocks unintended recipes.
- A conditional fix protects durability and upgrade levels when taking items off stands not approached since installing 1.0. Iron Gate still advises backups before removing valuable items from stands already encountered in 1.0.
- Other changes address an unloaded-zone crash, achievement messaging, Cart clearance through the Timberwood Drawbridge, and harvested mushroom visuals.

## Platform scope

Steam only in the cited announcement; crossplay remains supported. Check platform-specific notes for subsequent rollout.

## Dedicated servers and achievements

Banlists and whitelists accept legacy IDs again alongside the newer format. Server owners should check existing permission files after updating.

The new opt-in command is `yesiuseddevcommandsbutiwantmyachievementsanyway`. Iron Gate says it allows achievements despite earlier developer-command or mod use. This changes the FAQ's original lock guidance; see the [achievement guide](/valheim-1-0/achievements-cheats).
