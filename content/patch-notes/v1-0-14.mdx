**Valheim 1.0.14 released on September 17, 2026.** It was a broad post-launch repair covering controls, performance, multiplayer terrain, Deep North equipment, achievements, saves, and platform-specific display problems. Iron Gate said the staggered platform rollout remained crossplay compatible.

## What changed for players

- Added more keyboard bindings, including alternate dodge, hotbar rebinding, radial-wheel support, and the option to remove bindings.
- Added toggle blocking and an option to skip the opening cinematic.
- Corrected gamepad stick processing and restored the previous sheath-button behavior.
- Fixed achievement problems affecting **No Time for Snoozing**, **The Homesteader**, **The Architect**, and PS5's **Stronger Together**.
- Corrected server-client save behavior when a joining player used manual save.

## Deep North changes

Deep North battleaxes were corrected so they can cut every tree. The patch also fixed the Helmet of the Protector appearing directly at the Black Forge, added new trophies to Ballista targeting, improved the biome and Winding Tunnels music, and restored the correct music in Mörkhalla.

Jotun Puffs and Magecaps no longer respawn. That makes known harvests finite at a location, so avoid planning a permanent farm around their old behavior.

## Multiplayer terrain and joining fixes

The most consequential server fix disabled biome-data caching that could enter an invalid state and prevent remote-server joins. Iron Gate also repaired terrain changes that could cause multiplayer performance loss, portal failures, visible seams, or reverted terrain.

If a world still shows connection problems, compare the client and server builds, restart the host cleanly, and follow the [server-not-showing checklist](/servers/server-not-showing). Back up the world before attempting terrain or save recovery.

## Server-owner checklist

1. Update the server and every client to the same current build.
2. Create a fresh [world backup](/servers/world-backup-restore) before loading an important world.
3. Test portals and previously modified terrain with one player before reopening the server.
4. Confirm custom keybinds and mods after the update; patch compatibility does not guarantee mod compatibility.
