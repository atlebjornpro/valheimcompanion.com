**Valheim 1.0.21 released on October 28, 2026.** It is mainly a correction patch for Deep North progression, Kall Fimbulbringer, achievements, multiplayer stability, and save synchronization. It also changes where three late-game foods are prepared.

## Deep North and Kall changes

- Kall's drops should no longer fall through the arena floor.
- Screen shake during the Kall fight was reduced.
- The damage-over-time portion of the Yagluth Aspect's Fire Nova was halved.
- Nord Greatsword variants now scale their damage correctly when hitting several targets.
- The Deep North mage helmet no longer requires a Moose Trophy to upgrade.
- Timberwood trees can drop cones. Those cones can be planted in more hospitable biomes rather than requiring another northern expedition for every tree.

These fixes make an update particularly worthwhile before a first [Kall attempt](/bosses/kall-fimbulbringer) or a large round of Deep North equipment upgrades.

## Food preparation changes

**Baked Poteitr, Kale Chips, and Oven Pancake now use the Food Preparation Table.** If a recipe appears to have vanished after updating, check that table before assuming the unlock was lost.

## Achievements, saves, and multiplayer

The patch repairs difficulty-related eligibility problems for **Mighty Halls, Comfort is King, The Homesteader, The Architect, and Survivor**. A Troll Trophy was also added to the Trophy Collector requirement.

Iron Gate additionally fixed rare multiplayer crashes and improved Steam save-cache synchronization when another program changes a save outside the game. Server owners should still stop the process and make an external backup before updating.

The Frost Foundry now records crafter ownership correctly. The notes warn that achievement progress remains tied to the network owner for now, and that a future fix may require an incompatible update. On a shared server, have the intended player perform the relevant crafting and verify credit before processing a large batch.

## Safe update checklist

1. Stop the server with no players connected.
2. Copy the active world, character data, configuration, and mod setup outside the live installation.
3. Update the server and every client to the same build.
4. Check mods before loading the production world.
5. Verify joining, saving, food recipes, achievement state, and Frost Foundry credit on a test session.

Use the full [dedicated-server update procedure](/servers/updating-a-server) when the world is persistent or modded.
